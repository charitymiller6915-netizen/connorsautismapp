CONNOR'S WORLD — PHONE APP PACKAGE

This is an installable Progressive Web App (PWA) source package.
To install on Android, it must first be hosted on an HTTPS website.
Then open the HTTPS address in Chrome on the phone, tap ⋮, choose Install app
(or Add to Home screen), and confirm.

Important:
- App data is stored in the browser's local storage on this device.
- Export a JSON backup before clearing browser data, uninstalling, or changing phones.
- This package is not yet published to Google Play and is not a native APK.
- To make it installable, upload the contents of this folder to a static HTTPS host
  such as GitHub Pages, Cloudflare Pages, or another static web host.
- Do not upload personal child observations into a public repository.
